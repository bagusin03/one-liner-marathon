One one-line comedy joke for make.fun's "One-Liner Marathon" bounty. `main.ts` writes a single 162-character joke to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only. A runtime guard enforces the gate (1–280 characters, one line, not only whitespace) before writing.

> I wanted to be a magician, so I practiced making my homework disappear — twenty years later I'm an accountant, and the trick still works, it just pays better now.

## Run it

```sh
node main.ts
```
